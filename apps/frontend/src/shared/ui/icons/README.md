Icons are copied from [Google Material Symbols](https://fonts.google.com/icons),
licensed under the Apache License 2.0 — compatible with this project's AGPL-3.0.

They are components rather than a webfont on purpose: a shop behind a firewall,
or offline, still draws its icons, and an operator's content-security policy
does not have to allow a Google domain for the interface to render.

Each file names the symbol it came from. Adding one means copying its path from
the official set, not drawing it.
